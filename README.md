# nmaus.ru — сайт ООО «НефтеМонтажАвтоматика»

Astro 5.0 статический сайт строительной компании НМА (нефтегазовая отрасль, Республика Коми и НАО).

## Стек
- **Astro 5.0** — статический генератор, ноль JS на проде, мгновенная загрузка
- **@astrojs/sitemap** — автоматический sitemap-index.xml
- **Vanilla CSS** — без Tailwind, без зависимостей фреймворков
- **Hosting**: VPS в РФ, Caddy, деплой через GitHub Actions

## Структура

```
src/
  data/         — все контентные JSON (services, cities, regions, company)
  pages/        — Astro-шаблоны и динамические маршруты
  layouts/      — BaseLayout с meta/og/jsonld
  components/   — переиспользуемые блоки (HeroBackdrop, TrebsaCase)
  styles/       — global.css
public/         — robots.txt, llms.txt, фавиконы, og-картинки
```

135 HTML-страниц генерируется при сборке (31.10.2026):
- `/` — главная
- `/about/` — о компании
- `/{region}/` × 2 (komi, nao)
- `/{region}/{service}/` × 18 (2 региона × 9 услуг)
- `/{region}/{service}/{city}/` × 90 (10 городов × 9 услуг)
- `/uslugi/{service}/` × 9 (общие страницы услуг)
- `/gorod/{city}/` × 10 (городские страницы)
- `/uslugi/` — каталог услуг
- `/contacts/` — контакты и адреса
- `/politika-pdn/` — политика ПДН
- `/404.html`

## Локальная разработка

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # сборка в dist/
npm run preview  # просмотр сборки локально
```

## Публикация — VPS в РФ

Актуальный процесс: push в `main` → GitHub Actions (`.github/workflows/deploy.yml`) → сборка Astro → rsync в `/var/www/nmaus.ru/` на существующем VPS. HTTPS обслуживает Caddy. Cloudflare используется для DNS, не для размещения сайта. Перед изменениями получать актуальный `origin/main`: 31.10.2026 локальная копия отставала на четыре опубликованных коммита.

```bash
npm run build
# После проверки изменений:
git push origin main
```

Серверные правила находятся в `/etc/caddy/Caddyfile`. `scripts/update-caddy-seo.py` — одноразовая точечная миграция SEO от 31.10.2026: по умолчанию показывает только проектируемый блок nmaus.ru; `--apply` проверяет конфигурацию и выполняет reload с восстановлением исходного файла при ошибке. Повторно после успешного применения не запускать.

## Проверка SEO

`python3 scripts/seo-audit.py [путь-к-отчёту.json]` читает sitemap и все его страницы, проверяет HTTP, title, description, H1 и canonical. Требуется сеть. Отчёты текущего аудита: `audit/2026-10-31/`.

Метрика: 112049973. События кликов: `contact_phone`, `contact_email`, `contact_whatsapp`. Для отчётов по конверсиям соответствующие JavaScript-цели нужно проверить/создать в кабинете Метрики. Эти события измеряют клики, а не состоявшиеся обращения.
